# Pinpointsmsvoicev2 Phone Number

Manage Pinpointsmsvoicev2 Phone Number resources using ytofu YAML.

## Basic Example

```yaml
resource:
  aws_pinpointsmsvoicev2_phone_number:
    example:
      iso_country_code: US
      message_type: TRANSACTIONAL
      number_type: TOLL_FREE
      number_capabilities:
        - SMS
```
