# Auditmanager Account Registration

Manage Auditmanager Account Registration resources using ytofu YAML.

## Basic Example

```yaml
resource:
  aws_auditmanager_account_registration:
    example:
```

## Deregister On Destroy

```yaml
resource:
  aws_auditmanager_account_registration:
    example:
      deregister_on_destroy: true
```
