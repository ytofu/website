# Servicecatalog Principal Portfolio Association

Manage Servicecatalog Principal Portfolio Association resources using ytofu YAML.

## Basic Example

```yaml
resource:
  aws_servicecatalog_principal_portfolio_association:
    example:
      portfolio_id: port-68656c6c6f
      principal_arn: "arn:aws:iam::123456789012:user/Eleanor"
```
