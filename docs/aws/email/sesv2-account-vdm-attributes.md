# Sesv2 Account Vdm Attributes

Manage Sesv2 Account Vdm Attributes resources using ytofu YAML.

## Basic Example

```yaml
resource:
  aws_sesv2_account_vdm_attributes:
    example:
      vdm_enabled: ENABLED
      dashboard_attributes:
        engagement_metrics: ENABLED
      guardian_attributes:
        optimized_shared_delivery: ENABLED
```
