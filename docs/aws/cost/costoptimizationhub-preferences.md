# Costoptimizationhub Preferences

Manage Costoptimizationhub Preferences resources using ytofu YAML.

## Basic Example

```yaml
resource:
  aws_costoptimizationhub_preferences:
    example:
```

## Usage with all the arguments

```yaml
resource:
  aws_costoptimizationhub_preferences:
    example:
      member_account_discount_visibility: None
      savings_estimation_mode: AfterDiscounts
```
