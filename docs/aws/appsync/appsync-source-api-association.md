# Appsync Source API Association

Manage Appsync Source API Association resources using ytofu YAML.

## Basic Example

```yaml
resource:
  aws_appsync_source_api_association:
    test:
      description: My source API Merged
      merged_api_id: gzos6bteufdunffzzifiowisoe
      source_api_id: fzzifiowisoegzos6bteufdunf
```
